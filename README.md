# NCR-ride-booking-analytics
End-to-end Uber NCR Ride Booking Analytics project using Python, SQL, and Power BI. Includes data cleaning, exploratory data analysis, business KPI analysis, SQL queries, and interactive Power BI dashboards.

## Project Overview

This project analyzes Uber ride booking data to understand booking trends, revenue performance, cancellation behavior, customer satisfaction, and operational performance.

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- SQL / MySQL
- Power BI

## Dataset

The dataset contains 150,000+ ride booking records and includes information about:

- Booking Date & Time
- Booking Status
- Customer ID
- Vehicle Type
- Pickup Location
- Drop Location
- Booking Value
- Ride Distance
- Driver Rating
- Customer Rating
- Payment Method

## Project Workflow

1. Data Cleaning using Python
2. Exploratory Data Analysis
3. Business Analysis using SQL
4. KPI Development
5. Power BI Dashboard
6. Business Insights & Recommendations

## Key KPIs

- Total Bookings
- Total Revenue
- Average Ride Distance
- Cancellation Rate
- Average Customer Rating
- Average Driver Rating

## Key Analysis

- Monthly Revenue Trend
- Vehicle-wise Booking Analysis
- Vehicle-wise Cancellation Rate
- Top Pickup Locations
- Top Drop Locations
